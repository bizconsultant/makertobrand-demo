# Pictures for the MakerToBrand demo

To replace a picture on the site, you can do either of these:

1. **Keep the same file name.** Upload your new photo into this `images` folder with the *exact same name* as the old one (for example `color-fabric.jpg`). After you commit, the page that already uses that name will show the new picture.

2. **Use a new file name.** Upload your photo with a new name, then open `js/settings.js` and change the path next to the picture you want to swap, for example `homeHero: "images/my-new-banner.jpg",`.

A step-by-step guide is in [HOW-TO-EDIT.md](../HOW-TO-EDIT.md). Key banners and founder portraits are listed in that settings file. Factory and product gallery photos also live in this folder — replacing a file with the same name updates those too.
